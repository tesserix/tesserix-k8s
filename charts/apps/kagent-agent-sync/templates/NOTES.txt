kagent-agent-sync ({{ .Values.namespace }}) installed.

  CronJob/kagent-agent-sync ({{ .Values.cron.schedule }}) renders agents matching
  "{{ .Values.registry.labelSelector }}" (registry ns "{{ .Values.registry.sourceNamespace }}")
  into kagent.dev SandboxAgent + RemoteMCPServer CRs in "{{ .Values.registry.targetNamespace }}",
  via {{ .Values.registry.endpoint }}/v0/export/kagent.

  kubectl get cronjob/jobs -n {{ .Values.namespace }} -l app.kubernetes.io/name=kagent-agent-sync
  kubectl get agents.kagent.dev,sandboxagents.kagent.dev,remotemcpservers.kagent.dev -n {{ .Values.registry.targetNamespace }} \
    -l app.kubernetes.io/managed-by=agentic-registry
  kubectl get sandboxagent <name> -n {{ .Values.registry.targetNamespace }} -o jsonpath='{.status}'

PREREQUISITES:
  • The rendered agents reference the GitOps-managed ModelConfigs configured by
    kagentModels; they must exist in "{{ .Values.registry.targetNamespace }}".
  • Agents are synced only if labelled "{{ .Values.registry.labelSelector }}". Authoring
    sets this on agents the operator wants controller-managed; ephemeral agents
    stay Job-dispatched.
