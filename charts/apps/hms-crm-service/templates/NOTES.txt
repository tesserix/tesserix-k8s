HMS CRM Service has been deployed!

This service provides:
- Lead and Campaign Management
- Feedback Collection
- Roster Management (Shift Templates, Shifts, Assignments, Time-Off)
- Promotions Management
- Jobs and Applications Management

1. Get the application URL by running these commands:
{{- if contains "NodePort" .Values.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "hms-crm-service.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "LoadBalancer" .Values.service.type }}
  NOTE: It may take a few minutes for the LoadBalancer IP to be available.
  You can watch the status of by running 'kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "hms-crm-service.fullname" . }}'
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "hms-crm-service.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo http://$SERVICE_IP:{{ .Values.service.port }}
{{- else if contains "ClusterIP" .Values.service.type }}
  export POD_NAME=$(kubectl get pods --namespace {{ .Release.Namespace }} -l "app.kubernetes.io/name={{ include "hms-crm-service.name" . }},app.kubernetes.io/instance={{ .Release.Name }}" -o jsonpath="{.items[0].metadata.name}")
  export CONTAINER_PORT=$(kubectl get pod --namespace {{ .Release.Namespace }} $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
  echo "Visit http://127.0.0.1:8080 to use your application"
  kubectl --namespace {{ .Release.Namespace }} port-forward $POD_NAME 8080:$CONTAINER_PORT
{{- end }}

2. API Routes (via Istio VirtualService):
   - /api/v1/crm/*        - CRM base operations
   - /api/v1/leads/*      - Lead management
   - /api/v1/campaigns/*  - Campaign management
   - /api/v1/feedback/*   - Feedback collection
   - /api/v1/roster/*     - Roster management
   - /api/v1/shift-templates/* - Shift template management
   - /api/v1/time-off/*   - Time-off requests
   - /api/v1/promotions/* - Promotions management
   - /api/v1/jobs/*       - Jobs and applications

3. Health Check:
   curl http://<service-url>/health
